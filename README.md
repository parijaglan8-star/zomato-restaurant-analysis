# Zomato Bangalore Restaurant Analysis

##  Project Overview
Analysis of 51,000+ Zomato restaurants in Bangalore to uncover 
insights about ratings, cuisines, cost, and ordering patterns.

## Tools & Technologies
- **NumPy** — Numerical computations & statistics
- **Pandas** — Data cleaning & manipulation
- **Matplotlib** — Data visualizations
- **Probability** — Distribution & likelihood analysis
- **Tableau** — Interactive dashboard

## Key Insights
-  **Lavelle Road** has the highest average rating
-  **North Indian** is the most popular cuisine
-  Average cost for two people is **₹415**
-  Restaurants with **table booking** have higher ratings (4.14 vs 3.62)
-  Weak correlation **(0.19)** between cost and rating
-  Only **17.8%** restaurants have rating above 4.0

## Dataset
Kaggle Zomato Bangalore Dataset — 51,717 restaurants, 17 features
🔗 [Dataset Link](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants)
